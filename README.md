# My-six-assignment

My-six-assignment is a modern workout library web application that helps users browse different exercises, view workout details, create a daily workout plan, and save workouts for later.

## 🚀 Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- DaisyUI
- React Toastify
- REST API
- LocalStorage

## ✨ Key Features

1. **Workout Library**
   - Browse different workouts and exercises.
   - View workout cards with exercise name, muscle groups, difficulty, duration, and calories.

2. **Workout Details**
   - View detailed information about each workout.
   - Includes equipment, sets, reps, duration, calories, rating, and instructions.

3. **Today's Workout Plan**
   - Add workouts to today's plan.
   - A maximum of 5 workouts can be added to the daily plan.
   - Users can mark completed workouts as done.

4. **Save Workouts for Later**
   - Save favorite workouts for later.
   - Remove saved workouts whenever needed.

5. **Responsive & User-Friendly Design**
   - Fully responsive design for mobile, tablet, and desktop.
   - Clean dark-themed UI with an easy-to-use interface.
   - Workout data is preserved using LocalStorage.

## 📌 Project Purpose

The main goal of FitLog is to provide a simple and user-friendly platform where users can explore workouts, organize their daily exercise plans, and keep track of their selected workouts.
